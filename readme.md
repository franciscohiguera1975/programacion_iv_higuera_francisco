## 🛠️ Tecnologías del Curso

A continuación se detallan los conceptos fundamentales de las tecnologías estudiadas a lo largo de la materia, organizadas por su ecosistema de desarrollo:

### Ecosistema Web y Multiplataforma (JavaScript / TypeScript)

* **Node.js**: Entorno de ejecución para JavaScript construido con el motor V8 de Chrome. Permite ejecutar código JavaScript en el lado del servidor, facilitando la creación de APIs y herramientas de automatización para el desarrollo móvil.
* **React Native**: Framework de código abierto creado por Meta que permite desarrollar aplicaciones móviles para Android e iOS utilizando JavaScript y React. Su principal ventaja es que renderiza componentes de interfaz de usuario totalmente nativos.

### Ecosistema Multiplataforma Nativo (Google)

* **Dart**: Lenguaje de programación de código abierto, optimizado para el desarrollo de aplicaciones cliente (móvil, web y escritorio). Es fuertemente tipado, compila a código de máquina nativo y es la base detrás de Flutter.
* **Flutter**: Kit de herramientas de UI (SDK) de Google para crear aplicaciones compiladas nativamente a partir de una única base de código. A diferencia de React Native, Flutter no usa componentes del sistema operativo, sino que dibuja su propia interfaz mediante su motor gráfico.

### Ecosistema Nativo Android (Google / JetBrains)

* **Kotlin**: Lenguaje de programación moderno, estáticamente tipado y con soporte oficial de Google para el desarrollo nativo en Android. Destaca por ser completamente interoperable con Java, expresivo y seguro contra errores comunes como el *NullPointerException*.

## 📂 Estructura del Repositorio

Los proyectos de este repositorio están organizados de forma modular:

* `├── nodejs-backend/` -> APIs de soporte y servicios backend.
* `├── react-native-apps/` -> Proyectos híbridos con interfaz nativa.
* `├── flutter-dart-projects/` -> Aplicaciones multiplataforma de alto rendimiento técnico.
* `├── android-kotlin-native/` -> Prácticas de desarrollo móvil nativo puro para Android.
